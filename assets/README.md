## About

I'm **Aboubekrin Sedigh**, a full-stack developer based in Mauritania. I build web and mobile applications for institutional operations, education, retail and community services.

My work connects responsive interfaces with structured data, role-based workflows and practical business needs. I contribute to the **Zidnni AI Max** ecosystem, including Arabic, French and English products with right-to-left interfaces.
